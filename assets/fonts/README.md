# Fonts

## Inter

`Inter.ttf` is the Inter variable font, used for every glyph PushOS draws on
the Push 2 display.

- Source: <https://github.com/google/fonts/tree/main/ofl/inter>
- Licence: SIL Open Font Licence 1.1, reproduced in `Inter-OFL.txt`

PushOS rasterises the font's default instance, which is the regular weight.
Typographic hierarchy on the display comes from size, colour and layout rather
than from a second weight, so only one file needs to ship.
